# Darius' Todo List - Fetch & Post

Welcome to the Darius' Todo List project! This application is designed to help you manage your tasks effectively while enhancing your coding skills through practical experience with fetching and posting data.

## Purpose

The primary objective of this project is to improve your coding ability and knowledge by providing hands-on experience with CRUD operations (Create, Read, Update, Delete) using a simple todo list application.

## Features

- User-friendly interface for adding, viewing, and managing tasks.
- Fetching tasks from an API and posting new tasks to demonstrate data handling.
- Clear and concise code structure to aid in learning and understanding.

## Getting Started

To get started with the Darius' Todo List project, follow these steps:

### Prerequisites

- Basic knowledge of HTML, CSS, and JavaScript.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Dabeldab/dariusp-todo-list-fetch-post.git
   ```
2. Navigate to the project directory:
   ```bash
   cd dariusp-todo-list-fetch-post
   ```

### Usage

Open the `index.html` file in your web browser to start using the todo list application. You can add tasks, view existing ones, and see how data is fetched and posted.
